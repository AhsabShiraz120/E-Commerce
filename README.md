# Book Worm — E-Bookstore Capstone

Full-stack e-commerce application for browsing and purchasing books, built for the
**AI Specialist — Cloud FullStack Capstone**.

**Stack:** Spring Boot 3.3 (Java 21) · PostgreSQL 16 · React 18 + Vite + TypeScript · Redux Toolkit · Tailwind CSS

**Architecture:** OpenAPI-first / spec-driven. `docs/openapi.yaml` is the single source of truth; backend controller interfaces and frontend TypeScript types are both generated from it.

---

Setup and run instructions are being added feature-by-feature. See the plan file for the phased delivery order.
